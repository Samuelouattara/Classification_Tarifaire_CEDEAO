❓ Comment utiliser ce système

  1. Saisissez une description détaillée de votre produit
  2. Complétez les informations complémentaires (valeur, pays, poids, quantité)
  3. Cliquez sur "Classifier le produit"
  4. Le système analysera la description et proposera la section appropriée
  5. Consultez les détails de la section et les codes tarifaires correspondants

💡 Exemples de descriptions efficaces

Animaux : "Cheval reproducteur de race pure", "Poules pondeuses vivantes"
Produits alimentaires : "Riz blanchi long grain", "Tomates fraîches", "Huile d'olive vierge"
Textiles : "Tissu 100% coton", "Chemise en soie", "Jean en denim"
Véhicules : "Voiture d'occasion diesel", "Camion de transport", "Moto 250cc"
